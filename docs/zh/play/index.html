输入一段提示词。回复会逐个 token 流式输出，途中每隔一个 token 就会被改写：反转、转大写、打乱、删除。每个 token 下方的条表示模型对它有多大把握。完全在你的浏览器里运行，无需 API key。

来源

你的 key 只留在这个浏览器里。页面直接从你的浏览器调用服务商接口，中间没有我们的服务器。只有勾选“记住”时才会保存（存在本设备的浏览器存储里）。任何兼容 OpenAI 的接口都能用，前提是它以流式方式返回带 logprobs 的 /chat/completions，并允许浏览器（CORS）请求；如果不允许，请求会被拦下，页面会提示你。

0 个 token 已改写 0 个 平均置信度 - 置信度：模拟值 有把握 ≥70%不太确定基本在猜 <40%

mock 模型只是这个页面里的一小段脚本，并不是真正的模型：它会挑一条预设回复，再编出看起来合理的置信度数字，所以这些条是模拟的。不过 token 规则是真的：分词器、变换和 rate 规则都与 Rust 工具完全相同（当 floor((i+1)*rate) > floor(i*rate) 时第 i 个 token 会被改写，所以 0.5 就是每隔一个）。鼠标悬停在 token 上可查看数值；点击或轻触被改写的 token，可以切换回原文。使用你自己的 key 时，token 和置信度都来自模型本身。

获取完整工具

every-other-token 能在你的终端或它自带的 Web 界面里，对 OpenAI 或 Anthropic 的实时流做同样的事，还提供困惑度、排名靠前的候选词、置信度门控、提供方对比，以及 JSON 和 CSV 导出。免费开源（MIT），用 Rust 编写。

安装
$ cargo install --locked every-other-token
$ every-other-token "Why is the sky blue?" --provider mock
